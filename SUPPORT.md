# Support

Aegis v0.1.0 is a source-available local CLI. There is no published support inbox, response-time promise, paid support plan, or commercial contact address in this release candidate.

After the repository location is published, use its issue tracker for non-sensitive questions and reproducible defects. Before opening an issue, check [Troubleshooting](docs/TROUBLESHOOTING.md), [Limitations](docs/LIMITATIONS.md), and the exact CLI help output for your installed version.

Do not post vulnerability details, provider exports, hostnames, IP addresses, credentials, tokens, or customer data in a public issue. For security concerns, follow [SECURITY.md](SECURITY.md).

When reporting a non-sensitive defect, include the Aegis version, operating system/Python version, command with secrets and local paths removed, sanitized input shape, and the relevant stage status/error. Do not attach raw enterprise vulnerability exports.
