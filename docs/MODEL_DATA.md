# Public model data sources

Aegis stores downloaded feed bytes and the local corpus under the user-specific data directory printed by `aegis model path`. Feed bytes are not bundled in the wheel/sdist. `aegis model refresh` is the only command that makes network requests; normal ingest/analysis/reports are offline. Each cached source is represented by URL, retrieval time, source `ETag`/`Last-Modified` when supplied, SHA-256, byte count, and parser record count in the local corpus/model metadata.

## Sources used in v0.1

| Source | Purpose and fields used | Usage/license considerations | Refresh and failure behavior | Provenance |
|---|---|---|---|---|
| [NVD 2.0 CVE JSON year feeds](https://nvd.nist.gov/vuln/data-feeds) | CVE ID, publication/modified timestamps, CVSS v4/v3/v2 base score and vector dimensions, and CWE identifiers. NVD features are model inputs. | NVD data is provided by NIST; consult its [legal disclaimer](https://nvd.nist.gov/general/legal-disclaimer) and respect any embedded third-party content. Aegis stores the operator's local feed copy and does not redistribute the cache in packages. | Per-year gzip JSON feeds; default six-year range, maximum eleven selected years; each compressed feed is capped at 128 MiB and streaming decompression at 2 GiB per file. On download/parse failure, a prior cache remains and corpus replacement fails closed. | Feed URL, fetch metadata, compressed-file SHA-256/bytes; CVE identity and source feed filename retained in the local SQLite corpus. |
| [FIRST EPSS daily data](https://www.first.org/epss/data) | CVE, `epss` probability, and percentile. EPSS is the training label (`epss >= 0.10`) and retained as separate observed evidence; it is not a feature. | Published free of charge; FIRST requests attribution in publications/products. EPSS estimates sensor-detected/shared exploitation activity, not all exploitation. Aegis documentation attributes FIRST/EPSS. | Uses the published current gzip CSV, not the API for bulk data. Cache reuse is bounded; CSV rows and total decompressed size are capped. Malformed rows are skipped only when the remaining documented columns/records stay parseable; malformed header/feed fails the corpus build. | Feed URL, retrieval metadata, full source SHA-256/bytes/parsed row count and snapshot retrieval time. |
| [CISA Known Exploited Vulnerabilities catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) | `cveID`, `dateAdded`, and `knownRansomwareCampaignUse`; exact KEV status is a separate corpus profile and finding signal, not the model target or feature. | CISA's KEV data is offered under CC0 terms; the [catalog page](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) links its license. No KEV data is included in Aegis packages. | Current JSON catalog, capped at 24 MiB. Invalid root/schema aborts corpus replacement; previous local corpus/model remain available. | Source URL, retrieval metadata, SHA-256, byte count, row count, exact CVE IDs and date-added values. |

## Deliberately not ingested as standalone v0.1 feeds

| Candidate | Decision and reason |
|---|---|
| CWE full taxonomy | The v0.1 corpus uses CWE identifiers already present in NVD records and groups by ID. It does not download or redistribute the full MITRE taxonomy. MITRE's [CWE terms](https://cwe.mitre.org/about/termsofuse.html) grant use for research/development/commercial purposes subject to attribution if copies of CWE itself are made. |
| OSV | Not a v0.1 bulk source. OSV's own [source inventory](https://google.github.io/osv.dev/data/) lists heterogeneous source licenses (including CC-BY, CC0, MIT, Apache, BSD, and CC-BY-SA). Each source/ecosystem would need individual provenance and license treatment; Aegis does not assume the aggregate is uniformly licensed. |
| CISA Vulnrichment | Not separately fetched in v0.1. The project is [CC0](https://github.com/cisagov/vulnrichment) and supplies CVE/SSVC enrichments, but overlaps CVE/NVD data, evolves its nested record structure, and may conflict with CNA-provided CVSS/CWE values. A future explicit adapter must preserve source precedence and SSVC versioning. |
| Public exploit repositories/metadata | Not used for training or feeds. Repository metadata and records can have distinct licensing, redistribution, completeness, and “exploit available” semantics. Aegis will not infer commercial-use/redistribution rights or treat a generic public exploit indicator as mature/weaponized evidence. |

No Trident feed database, ExploitDB corpus, trained model, calibration artifact, source scanner output, answer key, or source-specific fixture is used or shipped by this subsystem.
