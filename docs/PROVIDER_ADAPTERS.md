# Provider adapter reference

The user-facing, versioned provider contract and validation matrix are maintained in [PROVIDERS.md](PROVIDERS.md). This legacy file remains as a short compatibility pointer for earlier links.

All v0.1 adapters are file-first. Named-provider detection is content/schema based and requires a supported contract shape. Generic JSON collection discovery is bounded and does not recurse into opaque metadata. Source-native IDs, severity/risk fields, unmapped values, and provenance remain separate from canonical priority. No live commercial provider/API was exercised.
